Logo UNIFACS
===========
A interface tenta exibir uma imagem oficial a partir da página institucional
https://landing.unifacs.br/assets/img/og/og-image-unifacs.png

Para ter uma cópia offline, salve a logo institucional autorizada como:
    assets/logo_unifacs.png

Se a imagem não existir ou falhar a conexão, a interface conserva o texto UNIFACS.
